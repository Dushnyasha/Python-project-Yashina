# Raspisanie

Календарь учебных дедлайнов и оценок. Программа читает экспорт Telegram и таблицы XLSX, сохраняет задачи, статусы и оценки между запусками.

## Как запустить

1. Установите Python 3.10 или новее с компонентом Tkinter, в обычном установщике Python для Windows он уже есть.
2. Скачайте проект через **Code → Download ZIP** и распакуйте.
3. Откройте терминал в папке проекта и выполните:

```bash
python raspisanie.py
```

На Windows также можно использовать `py raspisanie.py`.
Если файлы Python открываются через Python, можно дважды нажать на `raspisanie.py`.
Отдельные библиотеки устанавливать не нужно.

## Как пользоваться

- **Импорт Telegram**, выберите ZIP, JSON или HTML-файлы экспорта.
  **Импорт папки**, выберите папку экспорта. Читаются все страницы,  включая вложенные папки. Если есть и HTML, и JSON, используется HTML.
  Архив 7z сначала распакуйте, затем выберите его папку.
- Нажмите день в календаре и выберите задачу. Справа можно посмотреть  источник, открыть ссылку, изменить статус и поставить оценку.
  Слева показаны просроченные задачи и дедлайны ближайших 14 дней.
  Задание с оценкой автоматически получает статус «Готово», включая оценку 0.
  День, где выполнены все задания, окрашивается в бирюзовый `#52CEB9`, при выборе такого дня цвет меняется на `#00BCA9`. Если есть незавершённые задания, цвет `#FF9B95`, при выборе `#FC7F73`. Дни без заданий остаются без цветной заливки, даже с заметками или при выборе.
- **Редактировать** меняет название, предмет, работу, дату, время и ваше описание.
  Ручные правки сохраняются при новом импорте, исходный текст остаётся отдельно.
  **Удалить** убирает выбранный дедлайн и не даёт повторному импорту вернуть его.
- **Заметка на день** сохраняет текст для выбранной даты, даже без заданий.
  Такие дни отмечены ✎. Кнопка **Заметки** открывает все записи списком, начиная с новых. Чтобы удалить заметку, очистите её текст и сохраните.
- В **ФИО и источники** укажите полное ФИО. Здесь же можно добавить ссылки Google Sheets и включить синхронизацию при запуске.
  Для повторных экспортов одного чата оставляйте то же название чата.
  В полях работают Ctrl+V на русской и английской раскладках, а также меню по правой кнопке мыши.
- Во вкладке **Оценки** можно загрузить ведомость XLSX или таблицу дедлайнов, а также ввести оценку вручную. Для изменения оценки в таблице нажмите её дважды.
  Импорт ведомости обновляет оценки и отмечает оценённые задания как готовые, даты заданий не меняются, новые дедлайны не создаются.
- **Правила** позволяют менять названия предметов, маркеры и веса оценок.
  Примеры есть в [гайде](RULES_GUIDE.md).
- **Экспорт .ics** сохраняет незавершённые задачи для другого календаря.
  Указанное время считается московским, задача без времени занимает весь день.

Оценки могут быть от 0 до 10. Ручная оценка важнее импортированной.
Чтобы снова использовать оценку из ведомости, очистите поле ручной оценки и сохраните. Пустая ячейка не считается нулём.

Повторный импорт объединяет совпавшие задачи и сохраняет статусы.
Если записи исчезли из источника, прежние данные остаются.
При ошибке синхронизации видны сообщение и данные последней удачной загрузки.
Два источника обрабатываются отдельно.

**Отменить последний импорт** убирает новые задачи последней загрузки и возвращает изменённые данные. Позднейшие ручные правки прежних задач, ручные оценки и заметки сохраняются. Новые задачи удаляются даже после их правки.
Импорт папки считается одной загрузкой, каждая ссылка при синхронизации отдельной.
Отмена работает только для импортов после этого обновления, история хранится между запусками.

**Очистить всё** удаляет задачи, оценки, заметки, историю и настройки, включая ФИО и ссылки, синхронизация выключается. Обе операции требуют подтверждения.

Если данные не подходят:

- Сообщение без понятной даты попадает в предупреждения, дата не придумывается.
- Несколько строк с одинаковым ФИО отменяют импорт ведомости.
- Повреждённый файл данных не перезаписывается, можно восстановить копию `.bak`.

## Какие таблицы подходят

В ведомости название листа должно указывать предмет, заголовки должны быть в первой строке. Нужен столбец «ФИО» и работы вроде «ДЗ 1», «Проект», «Экзамен».
Все слова ФИО должны совпасть, порядок слов и регистр не важны.

В расписании нужен лист со словом «дедлайн» в названии и тексты заданий со сроками в ячейках. Заголовок месяца с годом задаёт год для дат без года.
Другие структуры таблиц могут потребовать изменения кода.

Синхронизация работает с Google Sheets, доступными для скачивания без входа.
Закрытую таблицу скачайте как XLSX и импортируйте вручную.
Формулы Excel не выполняются, читаются их сохранённые результаты.

## Где хранятся данные

Весь код находится в `raspisanie.py`. Данные и настройки записываются рядом, в `studyflow_data.json`, предыдущая версия хранится в studyflow_data.json.bak`.
Не удаляйте эти файлы, если хотите сохранить свои задачи и оценки.
Личные данные и учебные таблицы в репозиторий не входят.
При обновлении замените файлы проекта, оставив свой JSON и его резервную копию.
При первом запуске новая версия проверит старые сроки и дубли, сохранит резервную копию перед исправлением и сообщит о найденных изменениях.

Можно импортировать из терминала, например `python raspisanie.py "папка экспорта"`.
Остальные параметры показаны командой `python raspisanie.py --help`.
Результаты проверок и ограничения есть в [TEST_REPORT.md](TEST_REPORT.md).
