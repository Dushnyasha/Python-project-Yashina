# Проверки StudyFlow

После обновления выполнены 83 автоматические проверки, все прошли.
Кроме тестовых сообщений и таблиц проверен последовательный импорт двух
экспортов Telegram. Личные данные и содержимое экспортов не публикуются.

Проверено:

- HTML, JSON, папки и ZIP, несколько страниц, ссылки и темы Telegram
- даты и время, отдельные сроки нескольких работ в одном сообщении
- повторный импорт, перенос срока и объединение копий на разных датах
- сохранение статусов, выбранной задачи и исходного текста сообщения
- сохранение предыдущего текста, если источник действительно изменился
- редактирование, удаление и защита от возвращения удалённой задачи
- заметки по дням, сохранение, удаление и порядок общего списка
- отмена импорта задач и оценок, повторной загрузки и отдельных ссылок
- сохранение заметок и позднейших ручных правок при отмене
- сохранение истории отмены между запусками и отсутствие записи при ошибке
- полная очистка данных, настроек и отключение синхронизации
- XLSX, поиск ФИО, ручные оценки, пустые ячейки и расчёт результата
- сохранение дат и состава заданий при загрузке тестовой ведомости XLSX
- автоматический статус «Готово» при ручной и импортированной оценке, включая 0
- привязка оценки к работе, выбор ФИО и загрузка уже сохранённых оценок
- восстановление статуса при отмене импорта ведомости
- цвет #52CEB9 для полностью выполненного дня и #00BCA9 при его выборе
- цвет #FF9B95 для дня с незавершёнными заданиями и #FC7F73 при его выборе
- отсутствие цветной заливки у дней без заданий, включая выбранные дни и дни с заметками
- независимая синхронизация источников и сохранение данных при ошибке
- чтение старого JSON, исправление прежних сроков и дублей, резервная копия
- повреждённые данные и сохранение прежнего состояния при ошибке записи
- отсутствие лишней записи JSON и повторной синхронизации при запуске
- сочетания клавиш для русской и английской раскладок, обработка вставки один раз
- логика календаря, смена дня и обновление списка заметок
- ICS, московское время, задачи без времени и длинные строки
- синтаксис Python, обычные многострочные блоки условий и циклов

Тестовые наборы запускались отдельно и в репозиторий не добавлены.
Логика окна проверена без дисплея, внешний вид и вставка в настоящем окне
Windows здесь не проверены. Живая загрузка Google Sheets не проверена,
ошибки сети имитировались. Для точного повторения проблемы с ведомостью
нужен исходный XLSX, проверка выполнена на тестовой таблице.
